# 👩‍💻 About Me

I am a **Cybersecurity student and SOC & Threat Detection enthusiast** building practical skills in **Security Operations, SIEM, security monitoring, log analysis, threat detection, and incident investigation**.

My approach to learning is hands-on. I build cybersecurity projects, work with security tools, practice through TryHackMe labs, and develop home lab environments to understand how security monitoring and investigation workflows operate in practical scenarios.

My current technical focus includes **Splunk, SIEM concepts, log analysis, alert triage, network security, Linux, and defensive security tools**.

I am particularly interested in starting my professional journey in **SOC and Cybersecurity Analyst roles**, while continuing to develop toward **Threat Detection, Incident Response, Threat Hunting, Security Engineering, and AI/ML applications in cybersecurity**.
